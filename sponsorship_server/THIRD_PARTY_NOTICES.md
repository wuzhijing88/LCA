# 赞助页面设计来源

页面的双栏首屏、赞助卡的标题 / 内容分区、按钮状态和感谢卡网格改编自 [shadcn-landing-page](https://github.com/leoMirandaa/shadcn-landing-page)。

- 源版本：`ae3716dbce5c8a26815222bb743994b5717938f1`。
- 来源组件：`src/components/Hero.tsx`、`Pricing.tsx`、`Testimonials.tsx`、`ui/card.tsx` 和 `ui/button.tsx`。
- LCA 改动：转为服务端 Jinja 模板与 `themes/sponsorship.css`；中文内容、亮暗配色、赞助金额选择、真实赞助记录、移动布局及支付流程由本项目维护。
- 原模板中的示例用户、远程头像、示例套餐和订阅文案不用于本页。运行时不依赖原模板站点、React 或第三方 CDN。
