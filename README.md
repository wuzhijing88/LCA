# LCA

LCA 是一套运行于 Windows 的本地桌面工作流自动化程序，发布形态为离线版。

本项目面向本地、视觉驱动、低延迟、多窗口的桌面自动化，不是企业级 RPA 平台。程序在本机完成窗口识别、输入模拟、图像匹配、文字识别和工作流调度，不提供云端账号中心、远程审批或在线机器人集群。

本仓库仅公布应用程序源码，供查阅、研究和按许可证再发布。仓库中不包含可直接运行的安装包、模型文件、输入驱动、虚拟环境和用户数据。单独克隆本仓库无法形成完整运行环境。

## 功能范围

- 以卡片和连线组织工作流，支持保存与执行
- 单窗口与多窗口任务调度
- 鼠标、键盘与滚轮输入
- 截图、图像匹配、OCR 与目标检测
- 条件判断、随机跳转、线程控制与子工作流
- 操作录制与回放

## 仓库内容

本仓库包含以下源码目录：

| 路径 | 说明 |
| --- | --- |
| `main.py` | 程序入口 |
| `app_core/` | 应用配置、启动与运行控制 |
| `services/` | OCR、图像匹配、截图及子进程服务 |
| `task_workflow/` | 工作流执行、运行上下文与进程代理 |
| `tasks/` | 任务节点实现 |
| `ui/` | 主窗口、设置、参数面板与工作流界面 |
| `utils/` | 输入、截图、窗口与运行时工具 |
| `themes/` | 界面主题 |
| `resources/` | 程序图标与声明文本 |
| `LICENSE` | 许可证全文 |

以下内容不纳入本仓库，仅存在于开发或运行环境：

- Python 依赖清单、虚拟环境和构建脚本
- OCR、YOLO 等模型文件
- Interception、AutoHotkey 等第三方运行文件
- 工作流、截图、日志、缓存和打包输出
- 本机配置与用户数据

用户数据默认保存在 `%LOCALAPPDATA%\LCA`。
